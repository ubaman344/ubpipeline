# UB Pipeline Website — Technical Handover

## Project overview

UB Pipeline is a responsive, single-page marketing website for a founder-led LinkedIn growth and pipeline service. The current version is a frontend-only website with no login, database, payment system, or private backend.

## Core technology

| Area | Technology | Purpose |
| --- | --- | --- |
| UI framework | React 19 | Builds the website interface from reusable components. |
| Language | TypeScript | Adds type checking and makes future development safer. |
| Application framework | Vinext | Provides a Next.js-compatible application structure powered by Vite. |
| Build tool | Vite 8 | Runs the local development server and creates production builds. |
| Styling | Custom CSS and Tailwind CSS 4 | Custom CSS provides the visual design; Tailwind is available for utility styling. |
| Icons | Lucide React | Supplies the interface and service icons. |
| Fonts | Geist, Geist Mono, Georgia, and Trebuchet MS | Geist is the primary interface font; Georgia and Trebuchet support the branded display treatments. |
| Runtime | Node.js 22.13 or newer | Required to install dependencies and run development commands. |
| Hosting runtime | Cloudflare Workers through Wrangler | Supports the production server generated by Vinext. |

## Visual implementation

- The colour system uses navy, slate blue, mist blue, and near-white tones.
- The dotted blue texture is stored in `public/ub-grid.png`.
- The logo is built with styled text and CSS details rather than a separate logo image.
- The hero pipeline visual, orbiting labels, connectors, cards, comparison table, and transitions are built with React and CSS.
- Lucide supplies icons for services, contact details, comparison states, and supporting content.
- Responsive layouts are handled with CSS media queries for desktop, tablet, and mobile screens.
- Motion is created with CSS keyframe animations, so no separate animation library is required.

## Running the website locally

Requirements:

- Node.js 22.13 or newer
- npm
- Visual Studio Code or another code editor

From the project folder, run:

```bash
npm install
npm run dev
```

Then open:

```text
http://localhost:3000
```

## Available commands

```bash
npm run dev
```

Starts the local development website.

```bash
npm run build
```

Creates and verifies the production build.

```bash
npm run start
```

Runs the production output locally through Wrangler.

```bash
npm run lint
npm run format
```

Checks and formats the source code.

## Recommended publishing process

1. Add the final Calendly booking link.
2. Complete a final desktop, tablet, and mobile review.
3. Create a GitHub repository for the source files.
4. Push the project to GitHub.
5. Connect the repository to the selected hosting provider or publish through the existing Sites hosting configuration.
6. Connect the final domain and confirm HTTPS.
7. Add analytics only after choosing the preferred analytics provider.

## Maintenance notes

- Most content changes can be made in `app/page.tsx`.
- Most visual changes can be made in `app/globals.css`.
- Update the LinkedIn, email, or Calendly links in the contact section of `app/page.tsx`.
- Run `npm run build` before every production deployment.
- Do not commit passwords, private keys, or `.env` credentials to GitHub.
